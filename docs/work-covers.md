# 作品集圖片：角色卡封面系列

作品集卡片使用與文章相同的「角色卡封面系列」：大而清楚的繁體中文標題、精緻奇幻插畫、星象細節，以及從 [8 種角色風格](article-cover-role-styles.md) 中依作品核心挑選的配色、材質與光效。角色本身不出現在新封面裡。這是視覺製作規則，不是自動生圖功能。

目前 5 件作品一件一圖。AI Team Quest 的主題本來就是角色卡，所以使用自己的正式角色卡封面；其他作品依內容選風格，完整圖片 Prompt 與出圖來源記錄在 `docs/design/work-cover-prompts.json`。

| 作品 | 風格來源 | 原因 |
| --- | --- | --- |
| AI Team Quest | 傳聲者・星途狐靈 | 使用作品本身已確認的正式封面。 |
| 12 週執行力陪跑營 | 築城者・晶甲犀牛 | 每週追蹤、穩定累積與交付。 |
| 金鑰鍊成器 | 守夜者・星環黑豹 | 密碼工具、檢查風險與保護資料。 |
| 梅爾的個人網站 | 開路者・熾角雄鹿 | 第一次建立自己的數位基地。 |
| 鮮茶樂排班系統 | 牽線者・苔角幼鹿 | 把人員、班表與庫存串成一套流程。 |

新作品先寫出用途、主要使用者及最有代表性的畫面，再選最貼近的風格。生成畫面的主體必須是作品內容，不畫角色或動物。不要拿虛構的介面畫面冒充真實產品截圖；實際介面需要另外從產品擷取。作品標題短版放在圖內，完整名稱、功能與狀態由卡片文字呈現。

所有作品卡片採 8:5 橫式封面，輸出 1200×750 WebP，圖中的字和主體留 8% 安全邊界。填入作品原稿的 `image` 與 `imageAlt` 後，由 `src/components/WorkGrid.astro` 統一顯示；不逐件複製卡片介面。封面應完整顯示，不裁切標題或滑過時放大。

以後可直接說「用角色卡封面系列幫這件作品做圖」；我會依作品內容挑風格與場景，畫面不放角色。想指定風格時，說「用守夜者的紫色星環風格做金鑰鍊成器」也可以，不需要記 Prompt 檔名。
