# 首頁維護

2026-10-17 採用 Merle 選定的第 2 版「編輯選讀」：米白底、黑字、黃色閱讀入口；左側主文章，右側最新文章與作者介紹，下方作品入口。

- 唯一實作：`src/pages/index.astro`，共用 `PageLayout`、`Header` 與既有網站色彩。
- 文章自動讀取 `content/posts/` 中 `draft: false` 的內容，按日期由新到舊；同日再依 id 排序。第一篇為主文章、接著兩篇顯示於側欄，其餘全部保留在文章頁。
- 主圖使用該篇 `image` 或正文第一張圖片；沒有圖片時直接顯示標題，不用庫存圖補位。
- 日期、描述、連結與閱讀時間取自真實文章。三篇既有文章另有首頁短標題；新文章預設使用完整標題，無須改版型。
- 作品由 `content/works/` 讀取，首頁固定選 AI Team Quest 與鮮茶樂；新增作品仍會出現在作品頁，首頁精選名單可在本檔 `selectedWorks` 調整。
- 小尺寸改為單欄；主圖為既有正式封面，箭頭與葉片使用 Bootstrap Icons（MIT），不增加前端執行框架。
- 設計稿、前後畫面與備份還原文件收在私人備份倉庫 `design/`；本專案根目錄 `design-qa.md` 記錄驗收。
